Round two: draw-list pass prototype (aether.render.spike.* kinds, spike branch only).
Apple M4 Pro, 24 GB, macOS 26.5.1, Metal, wgpu 29.0.1, rustc 1.97.1, release, 1280x720 offscreen, 30 warm-up + 200 measured frames.
--spin: the render actor polls for the previous frame instead of wgpu-hal's Metal fence wait, which sleeps in 1 ms steps (wgpu-hal 29.0.1 src/metal/device.rs:1907) and quantises frame times to ~1.27 ms; baseline-sleep shows the default.
--light: 3 indices per draw, so frame time is CPU and driver work, not triangles.
--repeat R: best of R runs by median frame time. The 'texture bind groups' column in q2 counts both runs of --repeat 2 (65 / 425 / 513 per build).
